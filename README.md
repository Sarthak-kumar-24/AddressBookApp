## UC4 – Delete Contact from Address Book

### Objective
Implement the functionality to delete an existing contact from the Address Book.

### Description
In this use case, the Address Book application allows users to remove a contact from the Address Book by searching for the contact using the person's name. Once the contact is found, it can be deleted from the Address Book collection.

### Features Implemented
- Search for an existing contact in the Address Book by name.
- Remove the selected contact from the Address Book.
- Update the Address Book after deletion.

### Technologies Used
- Java
- Object-Oriented Programming (OOP)

### Outcome
The Address Book application successfully allows users to delete an existing contact from the Address Book.
