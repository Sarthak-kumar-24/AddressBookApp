## UC21 – Add Multiple Contacts to Address Book Database Using Threads

### Objective
Implement the ability to add multiple contacts to the Address Book database simultaneously using multithreading.

### Description
In this use case, the Address Book application is enhanced to support adding multiple contacts to the database concurrently. Each contact insertion is handled by a separate thread, allowing faster processing and demonstrating parallel execution of database operations.

### Features Implemented
- Add multiple contacts to the database simultaneously.
- Use multithreading to perform parallel database insert operations.
- Improve performance by inserting multiple records concurrently.
- Ensure successful storage of all contacts in the Address Book database.

### Technologies Used
- Spring Boot
- Java
- Multithreading
- JDBC
- MySQL Database
- Maven

### Outcome
The Address Book application successfully adds multiple contacts to the database using threads, demonstrating concurrent execution and efficient handling of multiple database operations.
