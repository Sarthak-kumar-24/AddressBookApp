## UC16 – Retrieve Contacts from Database

### Objective
Implement the ability to retrieve contacts stored in the Address Book database.

### Description
In this use case, the Address Book application is connected to a relational database. The application retrieves all contact entries stored in the database and loads them into the Address Book application memory. This enables persistent storage and retrieval of contact data.

### Features Implemented
- Connect the Address Book application to a relational database.
- Retrieve all contact records from the database.
- Load the retrieved contacts into the Address Book application memory.
- Display the retrieved contacts for verification.

### Technologies Used
- Spring Boot
- Java
- Spring Data JPA
- MySQL Database
- Maven

### Outcome
The Address Book application successfully retrieves contact entries stored in the database and loads them into the application memory for further operations.
