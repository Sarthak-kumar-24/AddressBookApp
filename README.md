## UC22 – Retrieve Contacts from JSON Server using REST Assured

### Objective
Implement the ability to retrieve contacts from a JSON Server using REST API calls.

### Description
In this use case, the Address Book application interacts with a JSON Server to retrieve contact data using REST APIs. REST Assured is used within JUnit tests to send HTTP requests to the JSON Server and fetch contact records. The retrieved contacts are then loaded into the application memory.

### Features Implemented
- Send HTTP GET requests to JSON Server.
- Retrieve contact data using REST APIs.
- Use REST Assured to test API responses.
- Load retrieved contacts into the Address Book application memory.

### Technologies Used
- Java
- Spring Boot
- REST Assured
- JSON Server
- JUnit
- Maven

### Outcome
The Address Book application successfully retrieves contact data from the JSON Server using REST API calls and processes the retrieved information within the application.
