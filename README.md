## UC14 – Read and Write Address Book Data using CSV File

### Objective
Implement the functionality to store and retrieve Address Book data using CSV files.

### Description
In this use case, the Address Book application is enhanced to support reading from and writing to CSV files. The contact details are stored in a structured CSV format, allowing easy storage, retrieval, and portability of Address Book data.

### Features Implemented
- Write Address Book contacts to a CSV file.
- Read contacts from a CSV file and load them into the Address Book.
- Use a structured format for storing contact information.
- Ensure contact details such as name, address, city, state, zip, phone number, and email are properly stored and retrieved.

### Technologies Used
- Java
- Object-Oriented Programming (OOP)
- OpenCSV Library
- File Handling

### Outcome
The Address Book application successfully reads and writes contact data using CSV files, enabling structured storage and easy data exchange.
