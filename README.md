## UC11 – Sort Contacts Alphabetically by Name

### Objective
Implement the functionality to sort contacts in the Address Book alphabetically by name.

### Description
In this use case, the Address Book application organizes the stored contacts in alphabetical order based on their names. This helps users easily browse and locate contacts in a structured manner.

### Features Implemented
- Sort contacts alphabetically using **first name**.
- Display contacts in sorted order.
- Improve readability and organization of contact records.

### Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Collections Framework
- Comparator for sorting

### Outcome
The Address Book application successfully sorts and displays contacts alphabetically by name, making it easier to manage and navigate through the contact list.
