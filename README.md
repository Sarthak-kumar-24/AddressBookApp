## UC9 – View Persons by City or State

### Objective
Implement the ability to view persons grouped by city or state in the Address Book.

### Description
In this use case, the Address Book application organizes contacts based on their city or state. This allows users to easily view all persons belonging to a particular city or state in the Address Book.

### Features Implemented
- Group contacts based on **city**.
- Group contacts based on **state**.
- Maintain a mapping of city/state to the list of contacts.
- Display all persons belonging to a specific city or state.

### Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Collections (HashMap, ArrayList)

### Outcome
The Address Book application successfully groups and displays contacts according to their city or state, improving organization and accessibility of contact information.
