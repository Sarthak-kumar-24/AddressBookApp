## UC13 – Read and Write Address Book Data using File I/O

### Objective
Implement the functionality to store and retrieve Address Book data using file input and output operations.

### Description
In this use case, the Address Book application is extended to support file handling. Contacts can be written to a file for persistent storage and read back from the file when required. This ensures that contact data is not lost when the application stops running.

### Features Implemented
- Write Address Book contacts to a file.
- Read contacts from the file and load them into the Address Book.
- Persist contact information using file input and output operations.
- Maintain data consistency between the Address Book and the file.

### Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Java File I/O (FileReader, FileWriter)

### Outcome
The Address Book application successfully stores contact data in a file and retrieves it when needed, enabling persistent storage of Address Book information.
