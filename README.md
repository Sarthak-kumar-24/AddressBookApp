## UC2 – Add New Contact to Address Book

### Objective
Implement the functionality to add a new contact to the Address Book.

### Description
In this use case, the Address Book application allows users to add new contacts by providing their personal details. The contact information includes first name, last name, address, city, state, ZIP code, phone number, and email. The entered contact is then stored in the Address Book collection.

### Features Implemented
- Allow users to add a new contact to the Address Book.
- Capture contact details including:
  - First Name
  - Last Name
  - Address
  - City
  - State
  - Zip Code
  - Phone Number
  - Email
- Store the new contact entry in the Address Book.
- Display the added contact details after successful insertion.

### Technologies Used
- Java
- Object-Oriented Programming (OOP)

### Outcome
The Address Book application successfully allows users to add new contacts and store them within the Address Book system.
