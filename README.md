## UC12 – Sort Contacts by City, State, or Zip

### Objective
Implement the functionality to sort contacts in the Address Book based on city, state, or zip code.

### Description
In this use case, the Address Book application allows users to organize contacts by different location attributes such as city, state, or zip code. This helps users view contacts grouped or ordered according to their geographical information.

### Features Implemented
- Sort contacts based on **city**.
- Sort contacts based on **state**.
- Sort contacts based on **zip code**.
- Display contacts in the sorted order.

### Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Collections Framework
- Comparator for sorting

### Outcome
The Address Book application successfully sorts and displays contacts according to city, state, or zip code, improving organization and accessibility of location-based contact information.
