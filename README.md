## UC19 – Count Contacts by City or State Using Database Function

### Objective
Implement the ability to count the number of contacts in the Address Book database based on city or state.

### Description
In this use case, the Address Book application retrieves the count of contacts belonging to a specific city or state directly from the database. Database functions are used to calculate and return the count of matching contact records.

### Features Implemented
- Count the number of contacts in a particular **city**.
- Count the number of contacts in a particular **state**.
- Execute database queries using **JDBC**.
- Utilize database functions to perform counting operations.
- Display the total number of contacts for the specified location.

### Technologies Used
- Spring Boot
- Java
- JDBC
- MySQL Database
- Maven

### Outcome
The Address Book application successfully counts and retrieves the number of contacts in the database based on a specified city or state.
