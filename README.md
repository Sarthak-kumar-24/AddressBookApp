## UC8 – Search Person by City or State

### Objective
Implement the functionality to search for contacts in the Address Book based on city or state.

### Description
In this use case, the Address Book application allows users to search for contacts belonging to a specific city or state. The system scans through the stored contacts and displays all matching entries.

### Features Implemented
- Search contacts based on **city**.
- Search contacts based on **state**.
- Display all contacts that match the given city or state.
- Support searching across all contacts stored in the Address Book.

### Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Collections (ArrayList / HashMap)

### Outcome
The Address Book application successfully retrieves and displays contacts that belong to a specific city or state, making it easier to organize and locate contacts.
