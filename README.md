## UC10 – Count Contacts by City or State

### Objective
Implement the functionality to count the number of contacts in the Address Book based on city or state.

### Description
In this use case, the Address Book application calculates and displays the total number of contacts belonging to a specific city or state. This helps users understand how many contacts are associated with a particular location.

### Features Implemented
- Count the number of contacts in a given **city**.
- Count the number of contacts in a given **state**.
- Display the total count of contacts for the specified location.
- Utilize the existing contact collection to perform the count operation.

### Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Collections (ArrayList / HashMap)

### Outcome
The Address Book application successfully counts and displays the number of contacts belonging to a particular city or state.
