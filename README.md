## UC15 – Read and Write Address Book Data using JSON File

### Objective
Implement the functionality to store and retrieve Address Book data using JSON files.

### Description
In this use case, the Address Book application is enhanced to support reading from and writing to JSON files. The contact details are stored in a structured JSON format, allowing easy storage, retrieval, and data interchange.

### Features Implemented
- Write Address Book contacts to a JSON file.
- Read contacts from a JSON file and load them into the Address Book.
- Use structured JSON format for storing contact information.
- Ensure all contact fields such as name, address, city, state, zip, phone number, and email are correctly serialized and deserialized.

### Technologies Used
- Java
- Object-Oriented Programming (OOP)
- JSON Processing Library (Jackson / Gson)
- File Handling

### Outcome
The Address Book application successfully reads and writes contact data using JSON files, enabling structured storage and easy data exchange.
