## UC3 – Edit Existing Contact in Address Book

### Objective
Implement the functionality to edit an existing contact in the Address Book.

### Description
In this use case, the Address Book application allows users to modify the details of an existing contact. The user can search for a contact by name and update fields such as address, city, state, ZIP code, phone number, or email.

### Features Implemented
- Search for an existing contact in the Address Book using the contact name.
- Update contact information such as:
  - Address
  - City
  - State
  - Zip Code
  - Phone Number
  - Email
- Save the updated contact details in the Address Book.

### Technologies Used
- Java
- Object-Oriented Programming (OOP)

### Outcome
The Address Book application successfully allows users to edit and update the details of an existing contact.
