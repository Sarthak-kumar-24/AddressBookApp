## UC1 – Create Contact in Address Book

### Objective
Implement the ability to create a new contact in the Address Book application.

### Description
In this use case, the Address Book application allows users to create a contact entry with personal details such as first name, last name, address, city, state, ZIP code, phone number, and email. The contact is stored in the Address Book system and can be displayed when required.

### Features Implemented
- Create a contact entry in the Address Book.
- Store essential contact details including:
  - First Name
  - Last Name
  - Address
  - City
  - State
  - Zip Code
  - Phone Number
  - Email
- Display the contact information in a readable format.

### Technologies Used
- Java
- Object-Oriented Programming (OOP)

### Outcome
The Address Book application successfully creates and manages a contact entry with the required personal details.
