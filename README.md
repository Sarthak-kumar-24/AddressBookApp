## UC20 – Add Contact to Address Book Database using JDBC

### Objective
Implement the ability to add a new contact to the Address Book database using JDBC.

### Description
In this use case, the Address Book application allows adding new contact entries directly into the database using JDBC operations. Transactions are used to ensure data consistency when inserting records into the database.

### Features Implemented
- Insert a new contact record into the Address Book database.
- Use JDBC for performing database insert operations.
- Apply database transactions to maintain data integrity.
- Ensure that contact details are successfully stored in the database.

### Technologies Used
- Spring Boot
- Java
- JDBC
- MySQL Database
- Maven

### Outcome
The Address Book application successfully adds new contacts to the database using JDBC while maintaining reliable and consistent database transactions.
