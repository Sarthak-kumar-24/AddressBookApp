## UC6 – Add Multiple Address Books

### Objective
Implement the ability to manage multiple address books within the Address Book application.

### Description
In this use case, the Address Book application is extended to support multiple address books instead of a single one. Each address book can contain multiple contacts. Users can create and manage different address books for organizing contacts separately.

### Features Implemented
- Create multiple address books.
- Store contacts within different address books.
- Maintain a collection of address books.
- Access contacts from a specific address book.

### Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Collections (HashMap / ArrayList)

### Outcome
The Address Book application successfully supports multiple address books, allowing users to organize contacts into different address book categories.
